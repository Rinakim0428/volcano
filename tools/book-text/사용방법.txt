책 본문 내보내기 — 파일 입력 방식

1. ZIP 압축을 풉니다.
2. Book-Text-Studio.html을 최신 Chrome에서 엽니다.
3. 책 파일 선택을 누르고 EPUB, PDF 또는 UTF-8 TXT를 선택합니다.
4. 본문을 확인한 뒤 본문 TXT 다운로드, Markdown 또는 JSON을 누릅니다.

별도 설치 프로그램, 터미널 명령, 로그인, 서버가 필요하지 않습니다.
파일 내용은 브라우저 안에서 처리하며 업로드하지 않습니다.
압축에 들어 있는 예제.epub는 기능 확인을 위해 직접 만든 짧은 예제입니다.
특정 상용 도서의 본문 파일은 포함되어 있지 않습니다.

지원 범위
- EPUB의 읽기 순서에 따라 본문 추출
- 텍스트가 포함된 PDF의 페이지별 본문 추출
- UTF-8 TXT 읽기
- 전체 본문 TXT, 장별 Markdown, 구조화한 JSON 저장
- 진행 표시, 취소, 장별 미리보기

지원하지 않는 기능
- 밀리 계정 로그인과 온라인 서재의 책 자동 다운로드
- 밀리 .ncg 보호 파일, 암호화 EPUB/PDF의 보호 해제
- 이미지·스캔 PDF에서 글자를 읽는 OCR

따라서 이 도구는 밀리 앱의 보호된 책 본문을 자동으로 가져오는 완성 시스템이 아닙니다.
사용자가 제공한 읽을 수 있는 파일의 본문 변환 기능을 구현한 것입니다.

파일 한도: 128 MiB, EPUB 본문 항목/PDF 페이지 2,000개, 출력 본문 2,000만 글자.
PDF의 표·다단 편집·각주는 순서가 달라질 수 있어 원본과 대조해야 합니다.
부분적으로 이미지인 페이지에서는 이미지 속 글자가 포함되지 않습니다.

검증 내용
합성 EPUB과 한글 PDF로 실제 본문 추출 및 파일 다운로드를 확인했습니다.
장/페이지 순서, 오류 처리, 취소, 재선택, 외부 서버 요청이 없는 동작을 확인했습니다.
검증 환경은 Linux Chromium의 localhost입니다. 실제 macOS 실행과 밀리 계정의
도서 데이터로 검증한 것은 아닙니다. 현재 클라우드 브라우저 정책상 file:// 직접
실행은 테스트할 수 없었습니다.
